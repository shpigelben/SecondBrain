> [!question]
> A Pythagorean rtiplet is a set of three **natural** numbers, $a<b<c$, for which $a^{2}+b^{2}=c^{2}$. For example, $3^{2}+4^{2}=5^{2}$. There exists exactly one Pythagorean triplet for which $a+b+c=1000$. Find the product $abc$.

# Thing I managed to come up with
if $(a,b,c)$ is a pythagorean triplet any multiple $k$ of the entire triplet is also a triplet

$$
\begin{align}
a^{2} + b^{2} = c^{2} &\to (ka)^{2} + (kb)^{2} = (kc)^{2} \\
&\to \cancel{ k^{2} }[a^{2} + b^{2}] = \cancel{ k^{2} }c^{2}
\end{align}
$$

for $(3,4,5)$ the sum is $12$, and since 1000 does not divide by $12$ the triplet we're after is not from the same family $(k\cdot3, k \cdot 4, k \cdot 5)$.

==A triplet that no has no common divisor is a **primitive** triplet.==
# How to find the elusive triplet possibilities?


## Euclid's Formula
For $m<n\in\mathbb{N}$ Euclid's formula provides an corresponding Pythgorean triplet
$$
\epsilon \cdot\Big(2mn, m^{2}-n^{2}, m^{2}+n^{2}\Big)
$$
where $\epsilon=\begin{cases}1/2 &\text{if nm is odd} \\ 1 & \text{else}\end{cases}$

We begin by creating an implementation of Euclid's formula that accepts a tuple $(m,n)$ and returns the appropriate triplet $(a,b,c)$.

```python
from math import sqrt

def primitive_pythagorean_triple(m: int,n :int) -> tuple:
    if n>=m:
        raise ValueError("m has to be greater than n")
    if n*m % 2 != 0:
        e = 0.5
    else:
        e = 1.0

    a = 2*e*m*n
    b = e*(m**2 - n**2)
    c = e*(m**2 + n**2)
    return (a,b,c)
```

The constraint $a+b+c=N$ becomes $m(m+n)=N/2$. Using the following transformation $(u,v)\to(m,m+n)$ the constraint becomes $uv=N/2$, and the demand that $m>n$ becomes $u> v/2$. If we treat $u$ as our independent variable it means that it's range is therefore $(0,\sqrt{ N })$. Since we're looking only for integer values of $(u,v)$ we scan over the natural subset of the range, namely $(1,\dots, \lfloor \sqrt{ N }\rfloor)$ and we pick only the integer-valued targets. The following function takes $N$ and returns the products that satisfy the conditions

```python
def int_prod_of(N: int) -> tuple:
    M = int(sqrt(N))
    products = []
    for u in range(1, M+1):
        v = N/(2*u)
        # if v is a natural numbers
        if (v-int(v)) == 0.0:
            m = u
            n = v - u
            if m > n > 0:
                products.append((m,n))
    
    return products
    ```

finally we scan the list of $(m,n)$ products for $N=1000$ and print their corresponding triplet with its element sum and product

```python
mn_list = int_prod_of(1000)
for m,n in mn_list:
    triplet = primitive_pythagorean_triple(m,n)
    suum = triplet[0]+triplet[1]+triplet[2]
    prod = triplet[0]*triplet[1]*triplet[2]
    print(f'{triplet} -> sum={suum} -> prod={prod}')
```
