> [!QUESTION]
> A palindromic number reads the same both ways. The largest palindrome made from the product of two 2-digit numbers is $9009=91\times99$

We first create a helper function to help us identify whether a given number is a palindrome of not

```python
def _palindrome(n: int) -> bool:
    s = str(n)
    return s == s[::-1]
```

- apparently, every even number palindrome is divisible by 11
- a 3-digits times 3-digit is a 6-digit (even)
- at least one of the numbers must be divisible by 11

so the following simply creates all the 3-digit numbers divisible by 11

```python
def three_digit_numbers_divisible_by_11():
    n = 990
    numbers = []
    while n >= 110:
        numbers.append(n)
        n -= 11
    return numbers
```

Finally, we brute force all the combinations $n\times m$ that result in a palindrome $p$ and return a list of all 6-digit palindromes which we then sort to find the largest one

```python
palindromes = []
for n in three_digit_numbers_divisible_by_11():
    for m in range(999, 99, -1):
        p = n*m
        if _palindrome(p):
            palindromes.append((n, m, p))
            break

palindromes.sort(key=lambda x: x[2], reverse=True)
palindromes[0]
```

The answer is $979 \times 664 = \boxed{650056}$
