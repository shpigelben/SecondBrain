A thermodynamic system is a [dynamical system](Dynamical%20System.md) with an extremely large number of particles. It is therefore highly chaotic and cannot be described microscopically. When subject to constraints, a thermodynamic system eventually arrives at a [thermodynamic equilibrium](Thermodynamic%20Equilibrium.md) in which it exhibits macroscopic qualities (temperature, pressure, magnetization, etc) that persist throughout time. It is then possible to describe the system in equilibrium using those qualities which are better known as the [state variables of the system](Thermodynamic%20State.md).

A thermodynamic system has a set of state variables that reflect its nature. These are tied by a state function that describe the system in a thermodynamic equilibrium
