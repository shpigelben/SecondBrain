#TD1 #thermodynamics 

A thermodynamic state is one of many possible states of a [[Thermodynamic System]]. It can be viewed as a point in the state space of the system, spanned by the systems [[State Variables]]. 

In [[Thermodynamic Equilibrium|equilibrium]], the states of the system live on a manifold, determined by a [[State Function]] unique to the system.

___

When a set of $n$ parameters describes a system, it spans an abstract space known as [[State Space]] in which all possible states of the system exist. When a [[State Function]] introduces a relation between several of those variables, it confines the possible states of the system to a manifold in state space.

A thermodynamic state corresponds to a point in state space.
