Given a [[Bravais Lattice]] plane, a __lattice place__ is defined to be any plane containing at least __3 non-colinear__   lattice points.

Because of the translational symmetry of the Bravais lattice, any such plane will contain infinitely (in the case of an infinite lattice) many lattice point. Each plane can be treated as a two dimensional Bravais lattice.

__Family of lattice planes__ regards any set of perpendicular planes, each essentially contains the 2D lattice. Each family of planes contains as a whole the entirety of lattice points.

### Reciprocal Lattice
For any family of lattice planes separated by distance $d$, there is a set of [[Reciprocal Lattice| reciprocal vectors]] that are perpendicular to the planes, the shortest of which has length of $2\pi/d$.

Conversely, for any reciprocal vector $\mathbf{K}$ there is a family of lattice planes normal to $\mathbf{K}$ and separated by a distance $d$ where $2\pi/d$ is the length of the shortest reciprocal vector parallel to $\mathbf{K}$

### Miller Indices
Three miller indices (in 3D) -  $h, k, l$ - describe a lattice plane that is orthogonal to the [[Reciprocal Lattice|reciprocal vector]] spanned by

$$ \mathbf{g}_{hkl} = h\mathbf{b}_1 + k\mathbf{b}_2 + l\mathbf{b}_3 $$

where the set $\{\mathbf{b}_i\}$ are the reciprocal primitive vectors.
