#note

Let $D$ be an open region in $\mathbb{C}$, and let $f:D \to \mathbb{C}$ be a complex function.
$f$ is **differentiable** at $z_{0}\in D$ if $\exists w_{0}\in\mathbb{C}$ such that
$$
w_{0} = \lim\limits_{z\to z_{0}} \frac{f(z)-f(z_{0})}{z-z_{0}} \equiv  \lim\limits_{z\to z_{0}} w(z)
$$
Or, in other words,
if $\forall \varepsilon, z_{0}$  $\exists\delta$ such that $z\in D\cap B^{*}_{\delta}(z_{0})$ satisfies $|w(z)-w_{0}|<\varepsilon$

- if a function is differentiable everywhere in $D$ it is **holomorphic** in $D$.
- if a function is differentiable everywhere in $\mathbb{C}$ it is **complete**.
