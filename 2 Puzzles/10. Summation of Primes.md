> [!question]
> The sum of the primes below $N=10$ is $2+3+5+7 = 17$.
> Find the sum of all primes below two million.

[Sieve of Eratosthenes](https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes)

```python
# implementation of the Sieve of Eratosthenes algorithm (N>2)
def primes_up_to(N: int):


    # Step 1: initialize a boolean array marking potential primes (True)
    is_prime = [True] * (N + 1)
    is_prime[0] = is_prime[1] = False  # 0 and 1 are not prime

    # Step 2: iterate through possible factors up to sqrt(N)
    p = 2
    while p * p <= N:
        if is_prime[p] is True:
            # Step 3: mark multiples of p as non-prime (False)
            for multiple in range(p * p, N + 1, p):
                is_prime[multiple] = False

        p += 1

    # Step 4: collect indices that remain True
    primes = [i for i, flag in enumerate(is_prime) if flag is True]
    return primes

primes = primes_up_to(int(2e6))
sum_of_primes = sum(primes)
print(sum_of_primes)
```
