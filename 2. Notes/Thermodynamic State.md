#note #thermodynamics #statistical-mechanics #concept

A thermodynamic state is one of many possible state a [thermodynamic system](Thermodynamic%20System.md) can be in. It can be viewed as a point in state-space, spanned by [state variables](State%20Variables.md). In [[Thermodynamic Equilibrium|equilibrium]], the states of the system live on a manifold, determined by a [[state function]] unique to the system.

# Equation of State
An equation of state relates several state variables that describe a [dynamical](Dynamical%20System.md)  or a [thermodynamic system](Thermodynamic%20System.md) in equilibrium.
$$f(x_{1}, x_{2}, ... ,x_{n}) = 0$$
In the $n$-dimensional state spaces spanned by $n$ parameters, the equation of state determines an $n-1$ dimensional manifold, on which all equilibrium states exist. The equation of state is system specific. Two systems, described by the same state parameters, are likely to have different equations of state.

State functions do not depend on the path taken between two states, as opposed to [[Process Function]]s which describe the transitions between equilibrium states and do depend on the path taken between two points in state space.
