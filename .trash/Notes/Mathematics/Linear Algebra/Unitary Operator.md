A unitary operator $\hat{U}$ satisfies the following
$$\hat{U}^{\dagger}\hat{U} = \hat{U}\hat{U}^{\dagger} = \hat{I}$$
We can define transformation of states using $\hat{U}$ as follows
$$\hat{U}\ket{\psi} \rightarrow \ket{\psi}'$$
Using those, we can write an inner product of two vectors as follows
$$ \braket{\psi' | \phi'} =

\left(\bra{\psi \hat{U}^{\dagger}}\right)
\left(\ket{\hat{U} \phi}\right) =

\braket{\psi|\hat{U}^{\dagger}\hat{U}|\phi}=

\braket{\psi|\hat{I}|\phi}=

\braket{\psi|\phi}
$$
the equality above goes to show that a unitary transformation, by definition preserves, [[Hilbert Space|inner product]].
