#TD1 #equilibrium #thermodynamics 

A state function relates several [[State Variables]] that describe a [[Dynamical System]]  or a [[Thermodynamic System]] in equilibrium. 

$$f \longmapsto f(x_{1}, x_{2}, ... ,x_{n}) = 0$$

When a set of $n$ parameters describes a system, it spans an abstract space known as [[State Space]] in which all possible states of the system exist. When a state function introduces a relation between several of those variables, it confines the possible states of the system to a manifold in state space.

![[State Space.png]]

Two very different systems can be described by the same set of parameters. The choice of state variables is obviously not unique. It is the state function that is unique to a system.

A system can undergo a [[Thermodynamic Processes | process]] in which it transitions continuously from one state to another. If the process is quasi static - that is a process where the internal thermodynamic equilibrium is never interrupted - the system continues to be described by the state function.

$$0=f(x_{1} , x_{2}, ... ,x_{n})  \longmapsto f(x_{1}' , x_{2}', ... ,x_{n}') = 0$$

State functions do not depend on the path taken between two states, as opposed to [[Process Function]]s which describe the transitions between equilibrium states and do depend on the path taken between two points in state space.
